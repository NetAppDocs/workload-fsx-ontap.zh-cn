= 访问FSx for ONTAP文件系统数据
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
您可以通过为NAS客户端挂载卷并为SAN客户端挂载iSCSI LUN、从内部访问FSx for ONTAP文件系统。

Amazon FSx for NetApp ONTAP 文档中的 link:https://docs.aws.amazon.com/fsx/latest/ONTAPGuide/supported-fsx-clients.html["访问数据"^] 提供了有关如何访问数据的信息。

您还可以在NetApp Workload Factory 中获取卷的挂载点。



[[get-mount-point-for-volumes-in-netapp-workload-factory]]
== 获取NetApp Workload Factory 中卷的挂载点

获取卷的挂载点，以便将该卷挂载为 CIFS 共享或挂载到 NFS 客户端。

.步骤
. 使用其中一个登录link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["控制台体验"^]。
. 选择菜单 image:workloads-menu-icon.png["汉堡菜单图标用于导航至存储、EDA、AI、数据库、VMware 和管理等工作负载。"] 然后选择“存储”。
. 在存储菜单中，选择*Volumes explorer*。
. 选择该卷的操作菜单，然后选择 *Basic actions*，然后选择 *View mount command*。
. 在挂载命令对话框中、选择*复制*以复制NFS挂载点或CIFS共享的命令。您将在终端中输入复制的命令。
. 选择 * 关闭 * 。
